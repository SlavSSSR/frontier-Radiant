# Подручные инструменты, смена пола и голоса

## Шанс успеха

У доступного этапа в хирургическом меню указан шанс с инструментом в руках. Если в руках есть несколько подходящих инструментов, выбирается включённый с лучшим шансом.

| Этап | Подручная замена | Успех |
| --- | --- | --- |
| Скальпель | Нож / заточка / стекло / кусачки | 90 / 80 / 70 / 60% |
| Зажим | Лом | 80% |
| Ретрактор | Лом | 90% |
| Костоправ | Гаечный ключ | 90% |
| Пила | Топорик / пожарный топор | 90 / 80% |
| Дрель | Электродрель / ручка / отвёртка | 90 / 80 / 60% |
| Прижигатель | Зажжённая зажигалка / включённая сварка | 80 / 70% |

Подручные замены увеличивают время этапа в 1,5–2 раза. Обычные хирургические инструменты сохраняют свой шанс, обычно 100%; это не защищает от загрязнения и инфекции. Костный гель без изменений.

При неудаче случайно выбирается одно последствие:

- потеря 15 единиц крови и увеличение кровотечения на 3;
- 5 режущего урона оперируемой части, если она поддерживает отдельный урон, иначе — пациенту;
- 5 режущего урона пациенту.

Для неорганического тела вариант с кровопотерей заменяется повреждением. Повторяется только неудачный этап; предыдущие успешные этапы не отменяются. Импланты при неудачном этапе не устанавливаются и не расходуются.

Ориентир для шансов — [руководство Wega](https://station14.ru/wiki/Wega:Хирургия). Это адаптация, не перенос всей их системы.

## Смена пола

Операция недоступна при отказе от ERP у хирурга или пациента, в том числе если статус изменён во время действия.

1. Откройте грудную и паховую области. Обе нужны до окончания операции.
2. Обычными операциями извлеките прежние половые органы и грудные ткани.
3. Выберите смену пола на женский либо мужской.
4. Пройдите этапы: для женского варианта установите донорские влагалище и грудные ткани, для мужского — донорский пенис. Орган берётся в руку на соответствующем этапе и расходуется при успешной установке.
5. Завершите реконструкцию прижигателем. Только тогда меняются пол и местоимения персонажа.
6. В появившемся окне выберите голос и сохраните. Доступны голоса из лобби для нового пола, есть прослушивание. Окно действует две минуты и только рядом с пациентом.

Обычная пересадка органов пол не меняет. Профиль персонажа в лобби не изменяется. Если закрыть выбор голоса после смены пола, сохранится совместимый текущий голос либо будет выбран совместимый автоматически.

## Только голос

Голова → открыть разрез → «Смена голоса» → зажим → скальпель → выбрать и сохранить голос. Пол и органы не меняются. Это отдельная обычная операция, а не ERP-операция.
